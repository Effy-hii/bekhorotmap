# מבוא עצמאי למסכת בכורות

גרסה עצמאית של המבוא החזותי למסכת בכורות מתוך מיזם ״הנותן בים דרך״. העמוד כולל את תשע התחנות, הפסוקים, המשניות, התמונות, הנתונים וההסברים הנדרשים לו, ללא תלות באתר המלא.

פתחו את `index.html` בדפדפן או הגישו את תיקיית המאגר באמצעות שרת קבצים סטטי. לפרסום ב־GitHub Pages יש לבחור בהגדרות המאגר את `main` ואת תיקיית השורש (`/`) כמקור הפרסום.

לבדיקת הקישורים והנכסים המקומיים: `node scripts/validate.mjs`.

הפניות למכון ממרא, לספריא ולערך במכלול הן קישורים חיצוניים למקורות המצוינים בעמוד. בסיום העמוד מופיע קישור ליצירת קשר עם הרב אפרים שרם ב־WhatsApp.
